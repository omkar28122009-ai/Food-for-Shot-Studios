FOOD FOR SHOT STUDIOS — ULTRA-PREMIUM MULTI-PAGE WEBSITE
=========================================================

PAGES
- index.html      Homepage with real embedded showreel, selected real film cards, and brand-logo wall.
- work.html       Portfolio with original public Vimeo film embeds, filters, search, and a bilingual video-player modal.
- expertise.html  Studio services.
- studio.html     Production approach.
- about.html      About page.
- contact.html    Enquiry form demonstration.

ASSETS
- assets/site.css       Shared responsive visual system and modal styling.
- assets/site.js        Navigation, filters, video modal, enquiry form behaviour, and English/Hindi studio assistant.
- assets/config.js      Optional configuration for contact email or secure AI endpoint.
- assets/portfolio-data.json  Editable list of selected public Vimeo project references.

IMPORTANT
1. Keep the folder structure intact. Open index.html from the extracted folder; do not move it away from assets/.
2. The original films play from the public Vimeo player embeds used in the studio's published commercial portfolio. Video playback requires an internet connection. The site does not bundle or redistribute those video files.
3. Portfolio cards use Vimeo thumbnail previews from vumbnail.com. If a thumbnail service is unavailable, a neutral fallback image appears; tapping a card still opens the Vimeo film if Vimeo is accessible.
4. The selected brand marks are image logos, not a typed text row. Daawat, India Gate, Tata Tea, Sony Alpha and ITC use direct image-logo sources, with favicon image fallbacks; other marks use brand favicon images. Internet access is needed to load remote logos. Brand marks belong to their respective owners; displaying a mark does not imply endorsement.
5. The visual brand wall combines brands identified in publicly titled films and brands included in the studio’s official brand-collaboration list. The legal note identifies the marks as their owners' property; use the wall only after confirming project rights and current approvals.
6. `assets/config.js` can be edited to connect a verified enquiry email or a secure chat backend. Never put a private AI API key into front-end JavaScript. The assistant otherwise falls back to built-in English/Hindi intent matching.
7. Contact form validation is front-end only until an email or secure form endpoint is configured. Do not publish it as a live lead-capture system until a destination is connected.
8. Test on mobile and desktop while online, since remote video, fonts and logo assets are not bundled locally.
